# Changelog

## 0.1.0

Initial release.

- Clause-level semantic diff and staging (index ↔ working tree)
- Move detection with atomic staging
- Historical diff between any two refs (read-only)
- Book-level compiled diff for bookdown and quarto projects
- Multi-sentence list items split into indented clause lines
- SCM panel integration
- Keyboard navigation (Alt+], Alt+[, Alt+S)
- Status bar clause position indicator
- Stage All / Stage All Files commands
- Ordered list renumbering suppression
